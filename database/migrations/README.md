# Migraciones SQL

Aquí van las migraciones cuando el stack es **MySQL** (Prisma/Drizzle) o migraciones SQL genéricas.

## Convención de nombres

`001_descripcion.sql`, `002_otra.sql`, ...

## Supabase

Si usas Supabase, las migraciones van en `supabase/migrations/` (creadas con `supabase migration new`).

## Estado

_Vacío — el asistente creará migraciones en la Fase 2D._
