# Migraciones Supabase

Generadas con:

```bash
supabase migration new nombre_descriptivo
```

El SQL va en archivos con timestamp en esta carpeta. Aplicar con `supabase db push`.

_Esta carpeta se crea al ejecutar `supabase init` en la Fase 2D._

Si aún no existe, el asistente puede ejecutar `supabase init` al configurar Supabase.
