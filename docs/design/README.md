# Fuente visual externa

Esta carpeta se usa en la ruta V2 para registrar/exportar Figma, HTML, capturas, design systems u otras referencias.

Guardar o enlazar:

- versión y fecha de la fuente;
- pantallas y estados;
- tokens, fuentes, iconos y assets;
- breakpoints y comportamiento responsive;
- permisos/licencia de assets;
- criterio de comparación visual.

No copiar archivos con restricciones de licencia ni credenciales privadas.
